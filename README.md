# AFWANVERSE

An interactive, multi-dimension personal portfolio built with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages.

## Preview
Open `index.html` in a browser, or serve the folder with `python -m http.server 8000` and visit http://localhost:8000.

## Publish on GitHub Pages
Copy the contents of this folder to the root of your `Afwans.github.io` repository (back up the old site first), commit and push. GitHub Pages will serve `index.html`.

## Customize
- Edit dimension copy, skills and cards in `script.js` (`dimensions` array).
- Update the journey entries in `sharedJourney` in `script.js`.
- Update palette and typography in `style.css`.
- Contact email, GitHub and LinkedIn links are in `index.html`.
- `assets/` contains original uploaded site images for future use. Only the favicon is currently displayed.

## Important
Experience summaries are deliberately high-level. Review them and remove any workplace information you do not have permission to publish. No private internal systems, source code or data are included. Project cards are descriptions of experience, not links to unpublished work. Add verified project URLs and a resume when ready.
